# 🚀 18 — Миграция на API 2.0.0

> [!abstract] О чём эта заметка
> Чек-лист внедрения глобальной переработки модели карточки и обучения (бэкенд v2.0.0). Пункты отмечаются по мере выполнения. Порядок этапов — снизу вверх по зависимостям: типы → API → сторы → UI.

## 📌 Суть изменений бэкенда

| Было (v1) | Стало (v2) |
| --- | --- |
| `front`/`back` — HTML-строки | `front`/`back` — **JSON-массивы блоков** (`{type, value}`) |
| Карточка без `title` | `title` — **обязательное**, уникально в рамках колоды |
| Нет подсказок | `hint1`, `hint2` (Optional) |
| Пагинация `page/per_page` в GET /cards | Убрана, возвращаются полные `CardResponse` |
| `CardLightResponse` (без back) в списках | Единый `CardResponse` везде |
| GET /cards/{id} → `CardResponse` | → `CardDetailResponse` (+ даты ревью, `review_history`) |
| PATCH /study → 200 или 204 | Всегда 200 + `{card, success}` |
| GET /study/study-cards | **Удалён** |
| GET /cloud-cards/{card_id} | **Удалён** (карточки приходят с превью колоды) |
| — | `is_suspended` (отложенная карточка), `in_learning`, `created_at`, `card_template_id` |

### Эталонный `CardResponse`

```json
{
  "id": "uuid",
  "deck_id": "uuid",
  "title": "название карточки",
  "front": [{ "type": "text", "value": "..." }],
  "back": [{ "type": "text", "value": "..." }],
  "hint1": "подсказка 1 или null",
  "hint2": "подсказка 2 или null",
  "difficulty": 3.32,
  "stability": 1.23,
  "in_learning": false,
  "card_template_id": "uuid или null",
  "created_at": "2024-01-15T12:00:00Z",
  "is_suspended": false
}
```

### `CardDetailResponse` (GET /cards/{card_id})

```json
{
  "card": { /* CardResponse */ },
  "last_review_datetime": "2024-01-20T15:30:00Z",
  "next_review_datetime": "2024-01-22T10:00:00Z",
  "review_history": [
    {
      "review_datetime": "2024-01-10T10:00:00Z",
      "rating": 3,
      "difficulty": 2.8,
      "stability": 1.5,
      "review_duration_ms": 5000
    }
  ]
}
```

> [!important] Критичные требования фронтенду
> 1. После ревью **заменять карточку по ID** в кэше из ответа `/study/review-card`, а НЕ сбрасывать кэш карточек колоды.
> 2. `PUT /cards/{card_id}` — частичное обновление: передаются только изменяемые поля.
> 3. `success: false` в ответе ревью → карточку нужно показать снова сегодня.
> 4. `is_suspended: true` → карточка не попадает в due-список.
