# 🗺️ 03 — Структура проекта

> [!abstract] О чём эта заметка
> Полная карта репозитория: что лежит в каждой папке, какие файлы за что отвечают. Используйте как справочник при навигации.

## 🌲 Верхний уровень

```
FlashMind_Frontend/
├── api/                  # axios-клиент, интерцепторы, auth-service
├── app/                  # МАРШРУТЫ Expo Router (экраны-обёртки)
├── assets/               # шрифты, иконки, логотипы, эмодзи-PNG
├── components/           # общие UI-компоненты (кнопки, инпуты, тосты…)
├── constants/            # константы (базовые URL API)
├── docs/                 # документация (+ этот vault)
├── feature/              # бизнес-модули: auth, decks, statistics
├── lexical-editor/       # отдельный Vite-субапп: Lexical в WebView
├── public/               # статика для веб-версии (favicon, index.html)
├── shared/               # типы моста RN↔WebView + генерированный HTML
├── storage/              # API-функции данных + AsyncStorage-кэш + хуки
├── store/                # глобальные Zustand-сторы
├── styles/               # Colors, Typography, Common
├── utils/                # чистые функции-хелперы
├── FlashMind/            # Xcode-проект Safari Web Extension
├── app.json              # конфиг Expo
├── babel.config.cjs      # Babel (module-resolver для алиасов)
├── metro.config.cjs      # конфиг Metro (svg-transformer)
├── eslint.config.js      # ESLint 9 flat config
├── docker-compose.yaml   # nginx-frontend :80
├── Dockerfile            # сборка веб-версии
├── nginx.conf            # конфиг nginx для SPA
└── package.json          # зависимости и скрипты
```

## 📁 api/ — транспортный слой

| Файл | Назначение |
| --- | --- |
| [`api/client.ts`](../../api/client.ts:1) | единственный axios-instance: timeout 15 c, `withCredentials`, подключение интерцепторов, обработка 404/500/сети |
| [`api/getMainServiceApiUrl.ts`](../../api/getMainServiceApiUrl.ts:1) | склейка `MAIN_SERVICE_BASE_URL` + путь |
| [`api/refresh.ts`](../../api/refresh.ts:1) | ручной вызов `/auth/refresh`, кладёт новый access-token в стор |
| [`api/interceptors/auth.interceptor.ts`](../../api/interceptors/auth.interceptor.ts:1) | авто-refresh при 401 + очередь ожидающих запросов |
| [`api/interceptors/error.interceptor.ts`](../../api/interceptors/error.interceptor.ts:1) | `handleApiError`: нормализация ошибок + тосты |

| [`api/services/auth.service.ts`](../../api/services/auth.service.ts:1) | login / register / refresh / logout |

## 📁 app/ — маршруты (Expo Router)

Файловая навигация. Каждый `index.tsx` — тонкая обёртка над экраном из `feature/`.

```
app/
├── _layout.tsx              # корневой Stack: шрифты, сплеш, тосты
├── (main)/                  # группа с плавающим TabBar
│   ├── _layout.tsx          # Tabs: decks · statistics · profile
│   ├── decks/index.tsx
│   ├── statistics/index.tsx
│   └── profile/index.tsx
├── decks/[id]/              # колода: просмотр, настройки, создание карт, изучение
│   ├── _layout.tsx
│   ├── index.tsx
│   ├── create-card/         # create · term-editor · text-editor · side-editor · image-editor
│   ├── settings/index.tsx
│   └── study/               # index + process
├── decks/cloud-decks/       # облачные колоды: список, превью, карточка
├── card/[cardId].tsx        # просмотр одной карточки
├── create-decks/index.tsx   # модалка создания колоды
├── home/ · loading/ · not-found/ · index/
├── login/                   # вход
├── register/[step].tsx      # регистрация по шагам
├── reset-password/[step].tsx# восстановление пароля (4 шага)
├── onboarding/[step].tsx    # приветственные экраны
└── settings/[step].tsx      # настройки профиля
```

Полная таблица маршрутов: [[04 Роутинг и экраны]].

## 📁 feature/ — бизнес-модули

Каждый модуль устроен одинаково: `screens/` · `components/` · `api/` · `styles/` · `types/` · `assets/`.

### feature/auth/
- `login/` — экран входа ([login.api.ts](../../feature/auth/login/api/login.api.ts))
- `register/` — шаги Email → ConfirmEmail ([registerApi.ts](../../feature/auth/register/api/registerApi.ts), стор `store/register.store.ts`)
- `reset-password/` — 4 шага восстановления (стор `resetPassword.store.ts`)
- `validators/` — email.validator, user-name.validator
- `components/CodeInput.tsx`, `hooks/useInterval.ts`

### feature/decks/
| Подмодуль | Экран | Суть |
| --- | --- | --- |
| `deck-list/` | MainDecks | список колод пользователя |
| `deck-create/` | CreateDecksScreen | форма создания колоды |
| `deck-by-id/` | DeckViewById | карточки колоды, шеринг, стать автором |
| `deck-settings/` | SettingsDeck | цвет, desired_retention, maximum_interval |
| `deck-create-card/` | CreateCard, SideEditor, TemplateSelect | конструктор карточек ([[09 Редактор карточек]]) |
| `deck-study/` | StudyDecksScreen | предпросмотр сессии изучения ([[10 Режим изучения SRS]]) |
| `deck-study-process/` | StudyDecksScreen (process) | сам процесс: показ карточки, оценка |
| `components/` | — | colorPalette, DecksView, SyncDeckModal, RichTextEditor… |

### feature/statistics/
- `screens/statisticsScreen.tsx` + графики: ProductivityGraph, CardsStatusGraph, DifficultyCardsGraph, StabilityGraph
- `components/AiInsightsScreen/` — AI-инсайты: Welcome / Progress / Problems / Plans / Recomendation / Closed
- `api/statsApi.ts`, `api/aiApi.ts`

Подробно: [[11 Статистика и AI]], [[12 Cloud Decks]].

- `hooks/useDecks.ts`, `hooks/useCards.ts` — фасады над сторами
- `types/types.ts` — Deck, Card, CloudInfo, payload-типы

Подробно: [[06 Состояние и кэш]].

- `lexical-editor/` — Vite+React суб-апп с Lexical (`src/Editor.tsx`, `src/plugins/EditorBridgePlugin.tsx`); собирается в один HTML
- `shared/types.ts` — контракт моста RN↔WebView (WebBridge, EditorBridgeState)
- `shared/generated/lexicalHtmlString.ts` — автогенерируемая строка HTML для WebView
