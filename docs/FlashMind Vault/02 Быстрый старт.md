# 🚀 02 — Быстрый старт

> [!abstract] О чём эта заметка
> Как поднять проект локально: требования, установка зависимостей, настройка `.env`, запуск на устройстве и в вебе, сборка Docker-образа.

## 📋 Требования

| Инструмент | Версия | Примечание |
| --- | --- | --- |
| Node.js | **18+** | обязательно |
| npm / yarn | актуальная | `npm install` |
| Git | любая свежая | клонирование |
| Expo Go (опционально) | iOS / Android | быстрый запуск без сборки нативного кода |
| Xcode / Android Studio | по необходимости | только для `expo run:ios` / `expo run:android` |

## 🔧 Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/ngdis13/FlashMind_Frontend.git
cd FlashMind_Frontend

# 2. Установить зависимости
npm install

# 3. Настроить .env (см. ниже)

# 4. Запустить Expo
npx expo start
```

## 🌍 Переменные окружения

Файл `.env` в корне проекта (не коммитится в git):

```dotenv
EXPO_PUBLIC_AUTH_API_URL=https://flashmind.ru
EXPO_PUBLIC_MAIN_SERVICE_API_URL=https://flashmind.ru
```

- `EXPO_PUBLIC_AUTH_API_URL` — базовый URL сервиса авторизации ([[07 Авторизация]]).
- `EXPO_PUBLIC_MAIN_SERVICE_API_URL` — базовый URL основного API (колоды, карточки, статистика) ([[05 API слой]]).

> [!warning] Локальная разработка
> Для отладки с локальным бэкендом укажите IP вашей машины в сети, например `http://192.168.0.106`. Значения читаются в [`constants/api.ts`](../../constants/api.ts:1) через `process.env.EXPO_PUBLIC_*`, поэтому после изменения `.env` нужен перезапуск Metro.

Префикс `EXPO_PUBLIC_` обязателен — только такие переменные попадают в клиентский бандл Expo.

## ▶️ Режимы запуска

| Команда | Что делает |
| --- | --- |
| `npm start` | Metro-сервер Expo (QR-код для Expo Go) |
| `npm run android` | сборка и запуск на Android (`expo run:android`) |
| `npm run ios` | сборка и запуск на iOS (`expo run:ios`) |
| `npm run web` | запуск веб-версии (`expo start --web`) |
| `npm run web:build` | прод-сборка веба (`expo export --platform web`) |

> [!tip] Rich-text редактор
> На мобильных платформах редактор карточек работает через WebView и использует **предсобранный HTML** из [`shared/generated/lexicalHtmlString.ts`](../../shared/generated/lexicalHtmlString.ts:1). Если меняли код суб-приложения [`lexical-editor/`](../../lexical-editor/package.json) — его нужно пересобрать и обновить генерированный файл. Подробности в [[09 Редактор карточек]].

## 🐳 Запуск веб-версии через Docker

Веб-экспорт раздаётся nginx'ом из контейнера:

```bash
docker compose up --build
```

- Контейнер `frontend`, порт **80**.
- Сборка: `Dockerfile` → `npm run web:build` → статика в nginx.
- Конфиг nginx: `nginx.conf` (SPA-fallback + проксирование API).

Подробнее: [[14 Safari-расширение и деплой]].
