# 🎨 13 — UI-кит и стили

> [!abstract] О чём эта заметка
> Общие компоненты (`components/`), дизайн-токены (`styles/`: Colors, Typography, Common), шрифты, иконки и эмодзи. Как собрать новый экран в стиле FlashMind.

## 🎨 Дизайн-токены — `styles/`

### [`Colors.tsx`](../../styles/Colors.tsx)

Единый объект `colors`: основной цвет приложения `mainColor`, тёмный вариант `darkMainColor`, `white` и палитра для статусов. Используется **везде** вместо хардкода (кроме редких мест вроде тостов в layout).

### [`Typography.tsx`](../../styles/Typography.tsx)

Компонент `<Typography variant="h1|h2|h3|..." color=...>` — единая типографика на шрифтах Montserrat. Варианты задают размер/вес/межстрочный интервал.

### [`Common.tsx`](../../styles/Common.tsx)

Набор переиспользуемых стилей `commonStyles.*` (например, `tabIconBox` — квадрат под иконку таба).

> [!tip] Правило
> Новый экран = `screens/XxxScreen.tsx` + `styles/xxx.styles.ts` (отдельный файл стилей) + токены из `colors`/`Typography`. Примеры: `deck-settings/styles/SettingsDeck.style.ts`, `statistics/styles/statisticScreen.styles.ts`.

## ✍️ Шрифты

Загружаются в корневом layout через `expo-font` ([[04 Роутинг и экраны]]):

| Семейство | Файлы из `assets/fonts/` | Где используется |
| --- | --- | --- |
| Montserrat | Regular / Medium / SemiBold / Bold | весь интерфейс (`Typography`) |
| Courier Prime | Regular | моноширинный стиль в редакторе кода |

## 🖼️ Иконки и графика

- **PNG-иконки** — `assets/icons/` (Plus, Delete, Edit, Settings, Reload, Return…), подключаются через `expo-image`.
- **SVG-иконки** — TSX-компоненты: `assets/icons/IconsTabBar/*` (табы), `assets/icons/TostIcon/*` (тосты). Транформер SVG настроен в [`metro.config.cjs`](../../metro.config.cjs).
- **Эмодзи Apple** — PNG из `assets/emoji-png/` (brain, rocket, lightbulb…) + хелпер [`assets/emoji/emoji.ts`](../../assets/emoji/emoji.ts); используются в онбординге/подсказках. Библиотеки: `react-apple-emojis`, `emoji-datasource-apple`.
- **Логотипы** — `assets/images/` (FlashMindLogo, cute/happy/sad/surprised звёзды, StarProgress, UserAvatar).
